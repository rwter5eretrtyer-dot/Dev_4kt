## Содержание

По материалам задания рассмотрены **11 поведенческих паттернов**, для каждого создан отдельный оригинальный пример на Java в контексте интернет-магазина.

1. **Template Method (Шаблонный метод)**. Фиксирует порядок проверки, оплаты и доставки заказа; виды заказов изменяют отдельные шаги.
2. **Mediator (Посредник)**. Пользователи обмениваются сообщениями через ChatRoom вместо прямых ссылок друг на друга.
3. **Chain of Responsibility (Цепочка обязанностей)**. Обращение передается по цепочке GeneralSupport и PaymentSupport до подходящего обработчика.
4. **Observer (Наблюдатель)**. Подписчики получают уведомление при изменении остатков товара.
5. **Strategy (Стратегия)**. Стоимость доставки вычисляется сменяемым алгоритмом самовывоза или курьера.
6. **Command (Команда)**. Одобрение и отмена заказа инкапсулированы в самостоятельные объекты-команды.
7. **State (Состояние)**. Заказ последовательно меняет поведение и статус NEW, PAID, SHIPPED.
8. **Visitor (Посетитель)**. Алгоритм расчета скидок вынесен из классов Book и Electronics в DiscountVisitor.
9. **Interpreter (Интерпретатор)**. Простое выражение доступа проверяет роль администратора или менеджера.
10. **Iterator (Итератор)**. Обход ProductCatalog выполняется единообразно без раскрытия внутреннего списка.
11. **Memento (Хранитель)**. Черновик заказа сохраняет состояние и восстанавливается после редактирования.

## Запуск

Для запуска требуется JDK 11 или новее.

```bash
javac -encoding UTF-8 src/BehavioralPatternsDemo.java
java -cp src BehavioralPatternsDemo
```

Программа демонстрирует все 11 паттернов, проверяет ключевые свойства через `check()` и завершается строкой:

```text
All 11 behavioral pattern checks passed
```

Каждый блок кода отмечен номером и именем паттерна. Синтаксис Java ориентирован на запуск без сторонних библиотек.
